# CGL Study Hub (v4)
Plain HTML + CSS + JavaScript on GitHub Pages + Firebase Auth + Firestore (free plans). Study material stays in Google Drive / YouTube as links.

* Upgrading from v3 → read **UPGRADE_v4.md**
* First-time setup (Firebase project, GitHub Pages, admin account) → same steps as before: enable Email/Password sign-in, create Firestore (asia-south1), paste `firestore.rules`, fill `js/config.js`, push to GitHub, add `<user>.github.io` to Firebase → Authentication → Authorized domains.
* Try everything without Firebase: open the folder with a local server (`python -m http.server`) – demo login `demo@demo / demo123`.
